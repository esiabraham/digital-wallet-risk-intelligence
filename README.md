
# Digital Wallet Fraud Risk & Financial Performance Intelligence

## Project Overview
An end-to-end data analytics portfolio project using the
Onyx DataDNA African Gig-Economy and Digital Wallet dataset.

## Business Problem
How can a digital wallet provider identify areas of financial
risk and improve payment reliability across different
markets, channels, and worker segments?

## Dataset
Source: Onyx DataDNA Challenge
Period: 2023–2024
Markets: Ghana, Nigeria, Kenya, and South Africa

## Tools
- MySQL
- Python
- Power BI
- GitHub

## Project Workflow
1. Business understanding
2. Data profiling and quality assurance
3. Data modelling
4. SQL analysis
5. Statistical analysis
6. Power BI dashboard
7. Business recommendations
